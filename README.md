# **Plataforma de Ensino - Programação e Inglês**

Este projeto foi desenvolvido para ajudar iniciantes a aprender tanto programação básica quanto inglês essencial para profissionais da área de tecnologia.

## **Objetivo**
A plataforma visa oferecer um ambiente de aprendizado acessível, abordando conceitos fundamentais de programação e habilidades essenciais do idioma inglês para facilitar a inserção no mercado de TI.

## **Tecnologias Utilizadas**

- **Front-end**: HTML, CSS, JavaScript
- **Back-end**: Java com Spring Boot
- **Banco de Dados**: MySQL com JPA

## **Funcionalidades**

- Módulos de ensino interativos
- Exercícios práticos
- Testes de conhecimento
- Progresso do aluno
